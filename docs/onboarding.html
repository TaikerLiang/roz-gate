From an empty repo to your first gated merge從空 repo 到第一次有 gate 的 merge

This page is the adopter's path: install the plugin, run init once, set the few knobs that matter, file one idea, and let patrol carry it to a merge you sign. Everything below is what the interactive guide explains, in the order you will actually meet it. Expect about an hour for steps 0–3 and one real feature for 4–5.

這一頁是採用者的路:裝 plugin、跑一次 init、設定少數幾個真正要緊的開關、開一張 idea,然後讓 patrol 把它一路送到由你簽收的 merge。下面的內容就是互動指南講的那些東西,但照你實際會碰到的順序排。步驟 0–3 大約一小時;4–5 用一個真實的 feature 走一遍。

0Ready? Four requirements and one honest question準備好了嗎?四個需求、一個誠實的問題

5Patrol — the "what's next" buttonPatrol——「接下來呢」按鈕

  
One pass: scan every open issue's labels, act on one in-loop issue whose labels already authorize a step, triage the whole inbox, and report what waits on you. Run it by hand whenever you wonder what's next, or schedule it (every 30 minutes is typical) once enough is in flight. It never applies a gate label.

  
一趟:掃過每張 open issue 的標籤,對一張標籤已授權的 loop 內 issue 動作,把整個 inbox triage 一遍,然後回報有什麼在等你。想知道接下來做什麼就手動跑;飛行中的事夠多了就排程(常見是每 30 分鐘)。它永遠不貼 gate label。

When it stops — four shapes you will meet停下來的時候——你會遇到的四種樣子

  
Stopping is the system working: agents are forbidden to guess. Each shape tells you where to look.

  
停下來就是系統在正常運作:agents 被禁止用猜的。每種樣子都告訴你該看哪裡。

  

    
status: blockedAn abnormal halt: a command hit something it cannot or must not decide and left an issue comment with evidence and a recommendation. Decide, clear the label; the step re-runs clean. It is not an agent waiting for an answer — that looks like open threads.異常停機:指令碰到它不能或不該決定的事,留下一則含證據與建議的 issue 留言。你決定、清掉標籤;步驟從乾淨狀態重跑。它不是 agent 在等你回答——那會長成開著的 threads。

    
processing + a phase labelA run was killed mid-flight. The phase label says where; clear the lock and re-run — commands are idempotent on re-entry.一次執行被中途砍掉。階段標籤說明死在哪;清掉鎖、重跑——指令重入是冪等的。

    
illegal label state非法標籤組合Two track: labels, fast with a spec-stage status… A command found it and stopped on purpose. Fix the labels by hand; commands never repair them.兩個 track:、fast 配 spec 階段的 status…指令發現後故意停下。手動把標籤修好;指令從不自行修標籤。

    
QA CR stays a draftQA CR 一直是草稿QA paused on an open question. Look for an unresolved thread on the spec CR, or in-spec-review on the issue.QA 停在一個未解的問題上。去 spec CR 找未 resolve 的 thread,或 issue 上的 in-spec-review。

  

  

    
Leaving, if you ever do哪天要離開的話

    
Two steps, in this order: /roz-gate:uninit in each adopted project (it refuses to run mid-flight, then removes what init installed; labels are kept, specs and the acceptance suite are yours), and only then /plugin uninstall roz-gate — uninstalling first deletes the cleanup command with it.兩步,照這個順序:先在每個採用的專案跑 /roz-gate:uninit(飛行中會拒絕;然後移除 init 裝的東西;標籤保留,spec 與驗收套件是你的),之後才 /plugin uninstall roz-gate——先解除安裝會連清理指令一起刪掉。
